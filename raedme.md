# Predictive Modeling Using Machine Learning

**Objective:** To develop a machine learning model that predicts outcomes using a given dataset.

**Tools Used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, and Seaborn.

**Algorithm:** Random Forest Classifier.

**Methodology:**

1. Collected and loaded the Iris dataset.
2. Checked the dataset for missing values.
3. Divided the data into 80% training and 20% testing sets.
4. Trained the Random Forest model.
5. Predicted outcomes using the test data.
6. Evaluated the model using accuracy, precision, recall, F1-score, confusion matrix, and ROC curves.
7. Visualized feature importance and model performance.

**Result:** The machine learning model was trained and tested successfully. Its performance was evaluated using classification metrics and visualizations.

**Conclusion:** This project provides practical experience in supervised learning, predictive modeling, model evaluation, and data visualization.
